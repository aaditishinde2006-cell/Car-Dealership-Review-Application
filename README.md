# Car Dealership Review Application

## Repository Name
Car-Dealership-Review-Application

## Project Name
Car Dealership Review Application

## Description
The Car Dealership Review Application is a web-based application that allows users to explore car dealerships, view dealership information, read reviews, and submit their own reviews.

- React
